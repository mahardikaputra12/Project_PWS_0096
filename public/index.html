Endpoint yang tersedia

Tiga kelompok endpoint, tiga level akses.

Publik — tanpa autentikasi

GET /

Cek status server

GET /api/v1

Daftar seluruh endpoint

Akun — butuh JWT (Authorization: Bearer)

POST /auth/register

Daftar akun baru, terima token JWT

POST /auth/login

Login, terima token JWT

POST /account/api-keys

Buat API key baru

GET /account/api-keys

Lihat semua API key milikmu

PATCH /account/api-keys/:id/revoke

Nonaktifkan API key

GET /account/api-keys/:id/usage

Statistik pemakaian API key
